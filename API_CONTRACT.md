# HAR Canvas prototype contract

Go backend + React/TypeScript/@xyflow/react frontend. Chinese user interface. Frontend owns `web/`; backend owns Go files. No authentication provider is bundled. Never auto-run uploaded HAR or execute commands returned by a model. Agent base URL/key/model fields are plain text and explicitly saved in browser only on clicking Save; no silent persistence. Imported HAR is not written to server disk. No browser automation in v1.

## API (JSON, errors `{ "error": "..." }`)

`GET /api/health` -> `{ "status":"ok" }`

`GET /api/har/example` loads the fixed local `-sample-har` path (default `samples/re.har`) once per process. Returns parse result plus `name`, `fileName`, `fileBytes`, `responsePreviewLimitBytes`, `previewedResponses`, `fullResponseAvailable`. All HTTP entries and complete request bodies/headers remain; only reference response bodies use 64 KiB previews, with optional Request `responseBodyTruncated` and `responseBodyBytes`. Source limit 256 MiB, initial JSON limit 32 MiB. Missing sample returns 404; no arbitrary file paths accepted. `GET /api/har/example/requests/{id}` returns `{request:Request}` from the same immutable cached snapshot with complete response body. Neither route invokes a model or replays requests.

`POST /api/har/parse` body `{ "har": <HAR object> }` -> `{ "requests": Request[], "summary": {"total":number,"api":number,"static":number,"domains":string[]}, "warnings":string[] }`. Preserve original request fields/cookies (not masked). Parser classifies static vs api vs document vs other. Frontend lets user drag requests from list; do NOT auto-connect HAR into a program. Request: `{id:string, method:string, url:string, domain:string, path:string, category:string, mimeType:string, status:number, duration:number, headers:Record<string,string>, body:string, responseBody:string, responseHeaders:Record<string,string>, query:Record<string,string>}`. IDs stable `req-1` etc.

`POST /api/agent/analyze` body `{ "config": {"baseUrl":string,"apiKey":string,"model":string}, "requests": Request[] }` -> `{ "summary":string,"suggestions": Suggestion[],"warnings":string[] }`. Suggestion: `{requestId:string,label:string,description:string,category:string,dependencies:string[],confidence:string,variables: [{name:string,source:string,description:string}]}`. Call `/v1/chat/completions` appended to user base URL that must end `/v1`. Do not silently fallback to fake AI. Return explicit error for failed provider/missing config. Restrict response IDs to original HAR IDs.

`POST /api/flow/run` body `{ "nodes": FlowNode[],"edges":FlowEdge[],"inputs":Record<string,string> }` -> `{ "status":"success"|"error", "steps":Step[],"variables":Record<string,any>,"output":any }`. FlowNode `{id:string,type:"block",position:{x:number,y:number},data:BlockData}`; FlowEdge `{id:string,source:string,target:string,sourceHandle?:string}`. BlockData `{kind:"input"|"request"|"extract"|"condition"|"output",label:string,description?:string,requestId?:string,method?:string,url?:string,headers?:Record<string,string>,body?:string,variable?:string,value?:string,source?:string,path?:string,operator?:string,expected?:string,template?:string}`. Input uses variable/value; request uses method/url/headers/body; extract uses source=node ID, path=json dot path (e.g. `body.data.id`) and variable; condition uses variable/operator eq|neq|contains|exists /expected; outgoing sourceHandle true|false chooses branch; output uses template. Templates `{{name}}` refer input/extracted variables and `{{nodeId.body.field}}` refer earlier step responses. Request step result `{status:number,headers:Record<string,string>,body:any}`. Step `{nodeId,label,kind,status:"success"|"error"|"skipped",durationMs:number,result:any,error?:string}`. Execute DAG topologically, deny cycles/invalid graphs, bounded timeout/body size, cookie jar for server-side session. Guard private/loopback/linklocal addresses including redirects and DNS on run API (test with mocked transport, not disable guard). Agent URL may use explicitly configured loopback for local providers but block cloud metadata endpoints; no arbitrary command execution. No replay until user clicks Run.

Frontend features: request upload/list/filter; built-in harmless sample HAR demo (public test API for optional replay, no registration); draggable request blocks; manual connect/delete/reposition; block library; inspector edits node settings including plain headers/body; agent settings visible text inputs, explicit save/clear, analyze button; suggestion labels in request list; runnable demo built of input -> output (no network); execution panel; project export/import JSON (excluding agent settings); export code JS or Go can be done frontend for the supported nodes, never fake or silently drop unsupported nodes. Prefer omit code export initially over incomplete code.

## Delivery

Root serves `web/dist` with SPA fallback, default loopback port 8090, `-addr` and `-web` flags (public bind only when explicitly selected at launch). Vite dev proxies `/api` to 8090. Docker multistage builds frontend and Go app, bind 0.0.0.0:8090. Prototype will be local first. No deployment to remote until user asks for deployment.
